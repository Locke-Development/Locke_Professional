### Why the library architecture matters

The library modules pair agreement templates with questionnaires, clause families, drafting rules, issue triggers and the workflow decisions those clauses depend upon. The product does not treat every registered Markdown file as a commercially usable legal instrument.

### Independent domain-service work

The source also contains **CM** (creative/marketing/IP), **PEA** (private estate administration) and **TAF** (trust/fiduciary) domain-service adapters and APIs. The release register classifies domain services as **internal**, so this portfolio does not promote them as separately production-ready customer subscriptions.
